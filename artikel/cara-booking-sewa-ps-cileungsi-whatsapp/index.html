Panduan Booking

Cara Booking Sewa PS di Cileungsi Lewat WhatsApp Bot

Booking PS4 atau PS5 di Eboni Space kini dapat dimulai langsung melalui WhatsApp bot. Anda cukup memilih konsol, paket jam sewa, serta TV bila diperlukan, lalu sistem mengirimkan kode booking otomatis.

Jika ingin sewa PlayStation untuk main di rumah, Anda tidak perlu menunggu balasan admin hanya untuk memilih unit dan paket sewa. WhatsApp bot Eboni Space membantu mencatat pilihan awal Anda dengan lebih cepat.

Setelah booking berhasil dibuat:
Anda akan menerima kode booking. Tunggu beberapa saat, admin Eboni Space akan menghubungi Anda untuk proses pengantaran, pin lokasi, dan kebutuhan khusus lainnya.
Mulai Booking Otomatis Lihat Harga Sewa

Langkah booking melalui WhatsApp bot

Ikuti langkah sederhana berikut untuk membuat booking awal. Pastikan mengirim satu pilihan dan menunggu respons bot sebelum melanjutkan ke pilihan berikutnya.

1

Mulai dari menu

Klik tombol Booking Otomatis di halaman ini, atau kirim pesan MENU ke nomor WhatsApp bot Eboni Space.

2

Pilih booking sekarang

Balas angka 1 pada menu bot untuk masuk ke proses booking.

3

Pilih konsol

Pilih 11 untuk PS4 atau 12 untuk PS5 sesuai unit yang ingin Anda sewa.

4

Pilih paket jam sewa

Bot akan menampilkan pilihan paket dan harga. Pilih kode paket yang sesuai dengan durasi sewa Anda.

5

Pilih tambahan TV

Untuk paket minimal 24 jam, bot akan menanyakan apakah Anda ingin menambah TV. Pilih 01 untuk tambah TV atau 02 untuk tanpa TV.

6

Simpan kode booking

Bot mengirim detail unit, paket, TV, total biaya, dan kode booking. Simpan kode tersebut sebagai referensi saat berkomunikasi dengan admin.

Contoh booking PS4

Misalnya Anda ingin booking PS4 paket 24 jam dengan tambahan TV. Kirim pilihan berikut satu per satu:

Contoh chat:

MENU
1
11
114
01

Arti contoh tersebut: mulai menu, pilih booking, pilih PS4, pilih paket PS4 24 jam, lalu pilih tambah TV. Kode paket dapat berubah bila daftar paket diperbarui, jadi selalu ikuti pilihan yang muncul di bot.

Apa yang dilakukan admin setelah booking?

Bot membantu membuat booking awal dan memberikan kode booking. Setelah itu admin akan menghubungi Anda untuk membahas detail yang membutuhkan konfirmasi manual, seperti pin lokasi, jangkauan pengantaran, biaya antar jika ada, jadwal, ketersediaan aktual, game yang diminta, dan ketentuan sewa.

Booking PS Sekarang Tanya Admin

Pertanyaan umum

Apakah booking melalui bot langsung dikonfirmasi?

Bot mencatat booking awal dan mengirim kode booking otomatis. Admin tetap menghubungi Anda untuk mengonfirmasi detail pengantaran, lokasi, jadwal, dan ketersediaan aktual.

Apakah saya harus mengisi nama dan alamat di bot?

Tidak. Bot hanya meminta pilihan konsol, paket jam, dan TV bila tersedia. Admin akan menghubungi Anda setelah booking untuk detail berikutnya.

Bagaimana jika saya salah memilih paket?

Ketik MENU untuk kembali ke menu awal, atau sampaikan perubahan yang diperlukan ketika admin menghubungi Anda.

Untuk pertanyaan promo, game, atau area antar, ke mana?

Gunakan tombol Tanya Admin. Admin dapat membantu mengecek promo yang aktif, pilihan game, jangkauan, serta ketentuan pengantaran.
